# Библиотека (учебный проект на SQLite)

Учебный проект: собственная база данных на Python с библиотекой `sqlite3`.
Тема — «Библиотека».

## Схема базы данных

База состоит из трёх таблиц. Пока в них общее поле `value`
(позже, на Этапе 5, оно будет переименовано).

```text
Таблица books (книги)
+----+------------------+-------+
| id |      title       | value |
+----+------------------+-------+
|  1 | Мастер и Маргарита | <число> |
| ...|                  |       |
+----+------------------+-------+
(id       — номер книги, ключ
 title    — название книги
 value    — пока общее числовое поле)

Таблица authors (авторы)
+----+-------------------+-------+
| id |       name        | value |
+----+-------------------+-------+
|  1 | Михаил Булгаков   | <число> |
| ...|                   |       |
+----+-------------------+-------+
(id    — номер автора, ключ
 name  — имя автора
 value — пока общее числовое поле)

Таблица readers (читатели)
+----+------------------+-------+
| id |       name       | value |
+----+------------------+-------+
|  1 | Иван Петров      | <число> |
| ...|                  |       |
+----+------------------+-------+
(id    — номер читателя, ключ
 name  — имя читателя
 value — пока общее числовое поле)

Plan переименований на Этапе 5:
- books.value   -> books.year       (год издания книги)
- authors.value -> authors.birth_year (год рождения автора)
- readers.value -> readers.age      (возраст читателя)
```

README будет дополнен на Этапе 9 (описание, установка, запуск).
